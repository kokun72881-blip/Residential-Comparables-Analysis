# Residential Comparables V6.2 Offline — Change Report

## Deliverable
- **Residential Comparables V6.2 Offline.html** — single-file, fully offline edition
- Source baseline: **Residential Comparables V6.1.3.html**

## 1. Files removed
- None removed from the repository.
- Runtime CDN script tags removed from the application HTML:
  - `https://cdn.tailwindcss.com`
  - `https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js`
  - `https://cdn.jsdelivr.net/npm/chart.js`

## 2. CDN removed
| Former CDN | Status in V6.2 |
|---|---|
| TailwindCSS Play CDN | Removed — replaced with embedded purged Tailwind CSS |
| SheetJS (xlsx 0.18.5) | Removed — library inlined in `<script>` |
| Chart.js (jsDelivr) | Removed — Chart.js 4.4.1 UMD inlined in `<script>` |

- No `<script src="…">` external references remain
- No remote `<link>` stylesheets
- No `fetch()` / dynamic download in application code

## 3. Embedded libraries
| Asset | How embedded | Approx. size |
|---|---|---|
| Application CSS (existing + offline UI) | Inline `<style>` | ~2 KB |
| Tailwind utilities (purged for used classes) | Inline `<style id="tailwind-embedded">` | ~14 KB |
| SheetJS / XLSX **0.18.5** (`xlsx.full.min.js`) | Inline `<script>` | ~0.86 MB |
| Chart.js **4.4.1** (`chart.umd.min.js`) | Inline `<script>` | ~0.20 MB |
| Application JS (V6.1.3 logic + offline safety) | Inline `<script>` | ~25 KB |

**Total single-file size:** ~1.09 MB (under 10 MB limit)

## 4. Offline verification result
On page load, startup checks:
- `XLSX` available (`typeof XLSX.read === 'function'`)
- `Chart` available (`typeof Chart === 'function'`)
- `localStorage` available (probe set/remove)

| Condition | UI |
|---|---|
| All OK | Green **"Offline Mode Ready"** beside title |
| Any missing | Red banner **"Offline Runtime Error - Required library failed to load."** |
| Chart only fails later | Chart section hidden; **"Chart unavailable"** shown; valuation continues |
| LocalStorage blocked | Amber warning; valuation continues with defaults / no persistence |

## 6. Remaining limitations
- File size is larger (~1.1 MB) due to inlined libraries (acceptable per Part 8).
- Tailwind is a **purged utility subset** of classes used by this app — not the full Tailwind CDN JIT engine. Adding new Tailwind class names in future edits requires regenerating the embedded CSS.
- Chart.js / SheetJS license comment strings inside the minified bundles may still contain `http://…` text; these are **not** runtime network requests.
- `readAsBinaryString` is retained for Excel import compatibility with V6.1.3 (works in Chrome / Edge / Brave on Windows).
- Offline Mode Ready indicates dependency presence at startup; it does not validate Excel file contents.

## Explicit non-changes
- Valuation formulas, adjustment factors, weighting, RVD logic, CSV export logic, and comparable calculation logic were **not** altered.
